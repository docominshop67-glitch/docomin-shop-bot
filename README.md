* `/bf-trade your_fruits:<ผลของคุณ> their_fruits:<ผลของเขา>` — คำนวณความคุ้มค่าของการเทรด เปรียบเทียบผลต่างมูลค่าเป็น % และตัดสินผลการเทรด (`MASSIVE WIN`, `WIN`, `FAIR`, `LOSS`, `MASSIVE LOSS`)

## 🌐 แผนและวิธีการทำให้บอทรันตลอด 24 ชั่วโมง (24/7 Hosting Plan)

เพื่อให้บอทและร้านค้า Docomin Shop ออนไลน์ตลอดเวลา ไม่มีสะดุด สามารถเลือกใช้งานได้ตามความสะดวก:

### ทางเลือกที่ 1: รันบนเครื่องคอมพิวเตอร์ส่วนตัว / PC (ฟรี 100%)
* ดับเบิลคลิกไฟล์ `start.bat` หรือเปิด PowerShell:
  ```powershell
  $env:NODE_TLS_REJECT_UNAUTHORIZED='0'; node index.js
  ```
* ใช้โปรแกรม **PM2** เพื่อให้บอทรีสตาร์ทอัตโนมัติหากเกิดข้อผิดพลาด:
  ```bash
  npm install -g pm2
  pm2 start index.js --name "docomin-bot"
  pm2 save
  ```

### ทางเลือกที่ 2: รันบน Cloud Free Hosting (Render / Koyeb / Railway) ร่วมกับระบบ Uptime ของเรา
1. นำโค้ดขึ้น GitHub แบบ Private
2. นำไป Deploy บน **Render.com** หรือ **Koyeb.com** (ฟรี)
3. นำ URL ของบริการมาใส่ในคำสั่ง `/uptime-add url:<URL>` ในบอทของเรา เพื่อให้บอทยิงปิงหาตัวเองทุก 2 นาที บอทจะไม่หลับตลอด 24 ชม.!

### ทางเลือกที่ 3: เช่า Cloud VPS (แนะนำสำหรับร้านค้ามือโปร ราคา ~100-150 บาท/เดือน)
* เช่า VPS Linux/Windows (เช่น DigitalOcean, Vultr หรือ VPS ในไทย)
* ติดตั้ง Node.js และรันด้วย PM2 บอทจะออนไลน์ 99.99% มี IP คงที่ และรองรับลูกค้าได้นับหมื่นคน
